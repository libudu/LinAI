# 互传网页版视频文件夹脚本

脚本文件：`easyshare-video-folders.user.js`，当前版本 `1.1.0`。适配本次手机提供的 Web EasyShare `web2.1.0.9`（前端 `main.6526953d.chunk.js`）。它在原视频模块旁显示文件夹列表，支持多选完整父目录筛选视频；不移动手机上的文件，也不额外发送上传、删除请求。

## 安装

1. 在电脑的 Chrome 或 Edge 安装 [Tampermonkey](https://www.tampermonkey.net/)，选择官网对应浏览器的扩展商店入口。
2. 在扩展管理页面打开 Tampermonkey 的详情，确保允许它访问 `http://192.168.1.91/`。Chrome 如果有“允许用户脚本”选项，开启它；旧版浏览器可按扩展提示开启开发者模式。参见 [官方说明](https://www.tampermonkey.net/faq.php#Q209)。
3. 点击 Tampermonkey 图标 → “添加新脚本”，删除编辑器里的默认内容。
4. 用文本编辑器打开 `easyshare-video-folders.user.js`，复制全部内容，粘贴到 Tampermonkey 编辑器，用 `Ctrl+S` 保存，并确认脚本已启用。
5. 刷新互传网页 `http://192.168.1.91:55666/`，连接手机后打开“视频”。脚本在页面启动阶段接入，因此安装后必须刷新。

## 使用

- 点击左侧文件夹勾选它，可以连续勾选多个文件夹，右侧合并显示它们直属的视频；再次点击取消勾选。无需按住 Ctrl。目录路径完整显示，同名文件夹分别列出。
- “全部视频”清除文件夹筛选并恢复完整列表。从“全部视频”状态点击一个文件夹后开始多选；取消最后一个勾选时显示空列表，再点击“全部视频”可恢复。
- 搜索框只筛选文件夹列表，不改变已勾选的文件夹，搜索结果外的勾选仍然生效。
- 文件夹后的数字是视频数量，面板顶部显示已选文件夹数量、当前视频数量和总数量。
- 原网页的排序、全选、单选、批量下载、删除继续使用。**多选文件夹后，全选只作用于这些文件夹当前显示的视频；更改文件夹筛选会清空原来的视频选择。**
- 点击原网页的刷新按钮，重新获取手机视频和文件夹数量。排序和刷新后会保留仍存在的文件夹勾选；消失的文件夹取消勾选，若已选文件夹全部消失则显示空列表。
- 图片、音乐、文件、搜索以及视频沙盒页不显示这个面板。
- 关闭脚本并刷新页面即可恢复原网页。

从旧版更新：打开 Tampermonkey 中原来的脚本，用此文件的完整内容替换，按 `Ctrl+S` 保存，再刷新互传网页。无需另建第二份脚本。

## 地址变化与排查

当前脚本头部是 `// @match http://192.168.1.91/*`，允许这个 IP 下端口变化。手机 IP 变更后，编辑这一行，替换成新 IP，再保存并刷新。仅配置你实际使用的手机地址。

如果面板没有出现：先确认 Tampermonkey 在当前页面显示此脚本已启用，并检查访问权限和“允许用户脚本”开关，再刷新页面。等视频列表加载完成后，面板应出现。黄色提示表示脚本没能接入当前网页；互传升级后，前端内部模块可能变化，需要重新适配。

脚本适配依据为当前网页源码及接口数据。仓库类型检查不会覆盖此独立 JavaScript 文件；安装到浏览器后的实际效果需在目标页面确认。
